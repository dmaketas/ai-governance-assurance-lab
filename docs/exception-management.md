# Exception management

Exceptions are explicit governance objects rather than free-text notes.

Each exception records:

- exception ID,
- affected control,
- rationale,
- approving authority,
- expiry date,
- compensating controls.

A valid exception gives only limited assurance credit. It does **not** change a missing control into an implemented control.

Expired, malformed or unapproved exceptions fail the policy gate.

This design is intended to make temporary risk acceptance visible, time-bound and reviewable.
